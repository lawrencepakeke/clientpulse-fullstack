# ClientPulse – Fullstack Analytics Dashboard

## Overview

ClientPulse is a fullstack web application designed to help businesses track client transactions, analyze revenue patterns, and understand which services and sources drive performance.

The application provides a clean dashboard where users can create, update, filter, and analyze transaction data in real time.

---

## Problem Statement

Many small businesses lack a simple way to track client transactions and understand where their revenue comes from.

ClientPulse solves this by providing a centralized dashboard that allows users to:
- Track transactions
- Analyze revenue trends
- Identify top-performing clients and services
- Filter data by category and source

---

## Tech Stack

### Frontend
- React (Vite)
- JavaScript
- CSS (custom modern UI)

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas (cloud database)
- Mongoose ODM

---

## Features

- User authentication (login system)
- Create, update, and delete transactions
- Real-time data fetching
- Search by client name
- Filter by:
  - Service category
  - Source (Referral, Website, LinkedIn, etc.)
- Analytics dashboard (stats panel)
- Responsive modern UI design
